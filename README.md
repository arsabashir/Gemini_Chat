# Google Gemini-Pro Chat Application

A Streamlit web application that allows users to chat with Google's GenerativeAI (Gemini-Pro). The application enables users to interact with Gemini-Pro in a conversational manner, with streaming responses and full chat history.

## About The Project

The Google Gemini-Pro Chat Application is a Streamlit-based web interface that facilitates interactive conversations with Google's GenerativeAI. Users can ask questions or engage in dialogue, receiving responses generated by the powerful Gemini-Pro model.

**Features**
- Real-time streaming responses
- Persistent chat history within a session
- Model picker (Gemini 1.5 Pro / Flash / legacy Gemini Pro)
- Adjustable temperature
- API key can be supplied via `.streamlit/secrets.toml`, an environment variable, or entered directly in the sidebar

## Prerequisites

- Python 3.9+
- A Google API key with access to the Gemini API — get one at [Google AI Studio](https://aistudio.google.com/app/apikey)
- `google-generativeai` and `streamlit` Python packages

## Getting Started

### 1. Clone / copy the project

```bash
git clone <your-repo-url>
cd gemini-chat
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv
source venv/bin/activate      # On Windows: venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Provide your API key

Choose **one** of the following:

**Option A — Streamlit secrets (recommended for local dev)**
```bash
mkdir -p .streamlit
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
# then edit .streamlit/secrets.toml and paste in your key
```

**Option B — Environment variable**
```bash
export GOOGLE_API_KEY="your-google-api-key-here"   # On Windows: set GOOGLE_API_KEY=...
```

**Option C — Sidebar input**
Just run the app and paste your key into the sidebar field at runtime (not persisted).

### 5. Run the app

```bash
streamlit run app.py
```

The app will open at `http://localhost:8501`.

## Deployment

This app can be deployed as-is to [Streamlit Community Cloud](https://streamlit.io/cloud):
1. Push this repo to GitHub.
2. Create a new app on Streamlit Cloud pointing at `app.py`.
3. In the app's Settings → Secrets, add:
   ```toml
   GOOGLE_API_KEY = "your-google-api-key-here"
   ```

## Notes

- `gemini-pro` is the legacy model name; Google's current recommended models are `gemini-1.5-pro` and `gemini-1.5-flash`. All three are selectable in the sidebar.
- Your API key is never written to disk by the app itself — it's only kept in Streamlit's session state (or read from secrets/env if you set it up that way).
